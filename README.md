# Free Proxy Bot

Telegram бот для получения бесплатных и платных HTTP/HTTPS прокси.

## Возможности

- Бесплатный доступ: 5 прокси в день
- Платный доступ: неограниченное количество прокси
- Автоматическое обновление списка прокси
- Статистика использования
- Проверка работоспособности прокси

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу |
| `/help` | Справка |
| `/proxy` | Получить 1 прокси |
| `/proxy N` | Получить N прокси (макс 20) |
| `/check` | Проверить прокси |
| `/buy` | Тарифы и оплата |
| `/buy_1` | Купить 1 месяц |
| `/buy_3` | Купить 3 месяца |
| `/buy_6` | Купить 6 месяцев |
| `/my_stats` | Моя статистика |

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/maleshovivan23-creator/bot-.git
cd bot-
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Получите токен

### 4. Настройте

В файле `bot.py` измените:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
ADMIN_ID = 123456789
```

### 5. Запустите

```bash
python bot.py
```

## Тарифы

- **Бесплатно**: 5 прокси/день
- **1 месяц**: $5 - неограниченные прокси
- **3 месяца**: $12 - экономия 25%
- **6 месяцев**: $20 - экономия 40%
